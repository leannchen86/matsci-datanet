## 5. Problems / gaps identified in the field or in the data (each: gap — evidence — who it hurts — [STATUS])

[OPINION grounded in SOURCE].

- B3: measured film κ (≤400°C, sub-µm, with boundary resistance, grain size, method, fit uncertainty) not linked to computed bulk κ — DM reference table bulk-only; diamond and AlN examples — hurts candidate ranking and threshold meaning; most accessible to an outsider but matters least for the stuck decision. [OPINION + SOURCE].
- Information lost along the measurement chain: setpoints vs actual temperature/plasma, TDTR fit covariances reduced to κ±σ, five samples reduced to mean±SD, raw data only in figures, negatives unpublished (NbP paper: data "in main text or supplementary"). [SOURCE/OPINION, illustrative not DM's own].
- Unrecoverable: past actual run conditions if only setpoints logged, chamber conditioning, destroyed samples, outcomes of never-attempted recipes, discarded raw TDTR data, unwritten operator observations. [OPINION].
- Test contamination: DM's grader has web search and training exposure, so a test set built from famous papers inflates scores. [OPINION].
- Irreproducibility (founders' own remark) caps any outcome predictor. [SOURCE + OPINION].
- The most important evidence (DM run records, grader internals/rubric text, partner-nanolab computers and notebooks) is access-restricted; "No compelling contribution is established until they answer ... has the grader ever been compared with actual deposition outcomes?" [OPINION].

## 10. Jargon that matters for the big picture
- BEOL (back-end-of-line) thermal budget — films must be deposited at ≤400°C so finished chip wiring survives; a hard constraint on recipes.
- κ (thermal conductivity, W/m·K) — how well heat flows; the target property. Bulk crystal value ≠ thin-film value.
- MLIP (machine-learned interatomic potential; PET-MAD) — a neural surrogate for quantum calculations; DM's "measurements" are its outputs.
- Thin-film deposition: PVD/sputtering, CVD/PECVD/MPCVD — ways to grow films; the "training run" whose hyperparameters are the recipe.
- Recipe grader / rubric judge — LLM-as-judge scoring recipes against expert rubrics; a proxy reward model never checked against ground truth.
- Censoring / selective labels — you only observe outcomes for items the gate approved; like training a classifier only on accepted loans.
- Exploration arm — deliberately running some rejected recipes to get unbiased labels (epsilon-greedy).
- Phase identification (XRD/GIXRD, Raman, TEM/SAED) — deciding which crystal structure formed; the labeling step, and it is noisy.
- Lonsdaleite — "hexagonal diamond", routinely confused with faulted cubic diamond; a canonical ambiguous label.
- TDTR — laser method for film κ; the reported κ is a model fit with interface terms (G1/G2), not a direct reading.
- Thermal boundary resistance (TBR) — heat-flow penalty at interfaces; dominates thin films.
- Group-held-out split — hold out whole labs/reactors/material systems, like leave-one-site-out CV.
- Leakage/contamination — grader with web search can look up the source paper of a test recipe.
- Combinatorial / co-sputter library — one wafer with a composition gradient; a way to get many labeled points per run (NREL HTEM-DB: >1,800 libraries, ~44 points each).

## 12. Smart or non-obvious ideas worth not losing (<=5)
- Treat the grader verdict as a forecast and the physical outcome as the target: pre-register every verdict before a run, and reserve a small budget to run randomly chosen refused recipes; otherwise no amount of data can overturn the expert rubric.
- Match the first curated system to whatever DM physically runs first (job post says PVD/co-sputter → sputtered AlN), not to the most common chemistry in the candidate list (B/C/N/H).
- Outcome labels need an ambiguity class and evidence strength, plus separate classes for "tool failure" and "run not finished" — failed material, failed equipment and inconclusive measurement are different labels.
- Test "summary fields vs full preserved record" explicitly; do not assume raw data helps, and use a no-search recall test to measure how much a literature-built test set leaks.
- The honest first deliverable is a question, not a tool: ask DM whether verdicts were ever compared with outcomes; if they already do this, or shift to amorphous/combinatorial work, abandon B1 and fall back to the film-κ linkage set.
