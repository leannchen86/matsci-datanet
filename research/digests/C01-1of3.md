## 5. Problems / gaps identified in the field or in the data
- Missing joins: no shared IDs across Matbench↔MP, RRUFF↔COD↔MP, polymer instruments, MPEA copies, composite laminates — hurts anyone merging datasets — [OWN-EXPERIMENT].
- Uncertainty dropped during curation (SciGlass, MPEA, steels, RRUFF headers; null in MP/HTEM) — hurts ML evaluation (noise floor unknown) — [OWN-EXPERIMENT].
- Benchmark targets are averages over unrecorded processing (steels; Tg medians) — hurts benchmark meaning — [OWN-EXPERIMENT].
- Identity beyond composition unrecorded: thermal history (glass), tacticity/chain length (polymer), grain size (alloys), architecture (composite) — [OWN-EXPERIMENT + OPINION].
- Inconsistent missing-value markers ('inf', "", "0", "-", "*", "----", NA, null, "Not specified") and wrong/absent units — [OWN-EXPERIMENT].
- Actual training data/labels not public (GNoME) or renamed/missing in re-packaging (MPtrj) — [OWN-EXPERIMENT].
- "Raw" data unavailable or not raw (HTEM 502s, RRUFF normalized) — [OWN-EXPERIMENT].
- Insufficient experimental variation/confounding (HTEM fixed 400 °C; composite conditioning; DSC single heating) — needs new experiments — [OPINION backed by data].

## 10. Jargon that matters for the big picture
- DFT — physics simulation that produces the labels; "functional" (PBE/GGA, r2SCAN, HSE06) = simulator fidelity setting; labels differ across settings.
- Formation energy / energy above hull — stability score relative to competing compounds; 0 = predicted stable.
- MP2020 corrections — hand-tuned label offsets added after simulation.
- Materials Project (MP) — the ImageNet-like DFT database; GNoME — DeepMind's predicted-crystal release.
- MPtrj — relaxation trajectory frames (energy, forces, stress) used to train ML force fields (CHGNet).
- Matbench — 13 fixed tasks with folds; the field's small benchmark suite.
- CIF — standard crystal-structure text file.
- Provenance — lineage from sample to file to label.
- Tg — glass transition temperature, method-dependent label.
- Tacticity / molar-mass distribution — polymer features absent from SMILES strings.
- Grain size / microstructure — hidden variable controlling alloy strength.
- Combinatorial library — one wafer with many compositions measured on a grid.
- EBSD — crystal-orientation map, image-like data.
- XRD / Raman / DSC / GPC — instruments producing a 1-D signal from which labels are fitted.
- Fictive temperature / thermal history — a glass's "training history", needed beyond composition.

## 12. Smart or non-obvious ideas worth not losing
- Taxonomy by "what must be specified beyond composition to define identity" (crystal: structure; glass: +thermal history; polymer: +chain distribution/tacticity; composite: +architecture; thin film: +substrate/thickness/deposition).
- Follow one material (quartz) through every representation to expose join gaps and label drift.
- Tag every gap as "documentation/linking fix" vs "needs new experiments" — the first kind is low-hanging fruit.
- Benchmark label audits (un-averaging steels; Tg spread) give a measurable noise floor for ML claims.
- SciGlass already stores errors/methods in coded scripts, and its lookup table maps each code to a summary column — a parser could recover dropped uncertainty without new experiments.
