## 10. Jargon that matters for the big picture
- CIF — standard text file for a crystal structure.
- esd — the "(2)" after a number: error bar on the last digit.
- Enantiomorph (#152 vs #154) — left/right-handed versions of one crystal; different label, breaks joins.
- K-alpha1/K-alpha2 doublet — lab X-ray tubes emit two close wavelengths, so truly raw peaks are double.
- Cell refinement — least-squares fit of peak positions to lattice constants; a fitted label.
- DIF — calculated reference diffraction pattern.
- Microprobe — spot chemical analysis (oxide wt%).
- GGA vs r2SCAN — two DFT approximations; like labelers with different bias.
- MPtrj — 1.58 M DFT relaxation frames for training force fields.
- Matbench — benchmark tasks cut from MP snapshots.
- GNoME — candidate-crystal release, not training data.
- S-N curve / R-value / runout — stress vs cycles to failure / min-max stress ratio / test stopped unbroken (censored label).
- Vf, lay-up — fibre volume fraction; ply stacking code such as (0)2.
- SciGlass — literature-compiled glass property database.

## 12. Smart or non-obvious ideas worth not losing
1. Trace ONE material (quartz) through the full chain — specimen files -> COD -> MP record -> MPtrj frames -> Matbench row -> GNoME snapshot — showing no identifier survives and even handedness flips.
2. Cheap forensic tests for "is this really raw?": all-integer counts, share of exact zeros, K-alpha2 shoulder, forced-zero endpoints, population-vs-sample SD recomputation.
3. Two-axis gap typology: gap type (observation, definition, join, uncertainty, variation, model limit) x fix type (documentation/linking vs new experiments), plus four-state missingness (absent / unknown / n/a / not in public release).
4. "Complete record, insufficient dataset": audit design-matrix coverage and confounding before calling a table ML-ready.
5. Assert-driven reporting: recompute every published number from the raw file and assert it against notes (caught 606 vs 781 cells and mis-read codes); privacy scans must unzip containers such as xlsx.
