# R01 — Materials Record Wall: atlas of 9 real materials records and what each one cannot support

## 1. What this slice is (2-3 plain sentences)
A finished HTML report ("Materials Record Wall", 5,573 lines as text) that opens 9 real public records across 6 material families (crystals, glasses, metals, polymers, thin films, composites; 6 experimental, 1 DFT, 1 ML, 1 DFT+ML) and scores each on 8 information layers. For every record it shows the native fields verbatim next to plain-language annotations, then a gap table: what reuse the record supports, what it cannot, which of 6 gap types is responsible, and whether the fix is documentation/linking or new experiments. It is a data-quality audit by example, not a survey; a build script re-reads the files and fails on any count/join mismatch.

## 4. Findings (each: claim — numbers/evidence — [STATUS] — plain-language "so what")

- Gap census — 72 gap rows: missing definition 41, missing join 23, missing observation 17, physical-model limit 15, missing uncertainty 14, insufficient variation 12; fix type: documentation/linking only 49, needs new data 9, both 14 — [OWN-EXPERIMENT] — about two-thirds of problems are cheap paperwork fixes; the remainder cannot be fixed by any curation.
- "RAW" is not raw (RRUFF R040031) — XRD "RAW" file has max exactly 100, 7,306 of 8,501 rows exactly 0, peaks shifted about -0.035 deg; Raman RAW non-integer; IR RAW 638 negatives; processed = RAW minus undocumented background in 11/11 pairs; 27 arrays share a 12-line header with no units/instrument/date — [OWN-EXPERIMENT] — stage labels inside files cannot be trusted; verdict: even all 33 files could not train structure->spectrum (one specimen, undefined intensity units, no instrument function).
- Same mineral, join fails on handedness — COD/RRUFF use space group #154, MP reports #152; Matbench holds one row of each; no ICSD/mp id in any of 37 RRUFF files — [OWN-EXPERIMENT] — joining databases on space-group number silently drops quartz.

## 5. Problems / gaps identified in the field or in the data (each: gap — evidence — who it hurts — [STATUS])
- Identity beyond composition is not recorded — silica density spread, CoCrFeMnNi YS 243-1371 MPa even within WROUGHT + 25 C, PLLA/PDLLA sharing one row — hurts anyone training composition->property models — [OWN-EXPERIMENT].
- Benchmarks drop source ids and versions — Matbench rows, matbench_steels (no source, method, license) — hurts leaderboard interpretation — [OWN-EXPERIMENT].
- Missing-value semantics are ambiguous everywhere — null / "" / 0 / "-" / inf / blank / "NaN" formula; n=1 std = 0.0; not-applicable marked same as absent (HTEM PLD fields, composites blanks) — hurts automated ingestion — [OWN-EXPERIMENT].
- Upstream data exist but are unreleased — raw EBSD patterns, GNoME training frames/splits ("Upcoming"), HTEM raw files, GREA source table (HTTP 404), SciGlass DOIs — hurts reproducibility — [OWN-EXPERIMENT/SOURCE].
- Units/definitions absent or wrong in machine-readable form — GNoME density unit, HTEM JSON, EBSD .ang unnamed columns, steel "Temperature" — [OWN-EXPERIMENT].
- Insufficient variation / confounded designs — composites environment x cure x campaign; HTEM single 400 C, NiO only 2.8-4.0%; one specimen for RRUFF — needs new experiments — [OWN-EXPERIMENT].
- Physical-model limits — PBE-level training frames near equilibrium only; 0 K single-functional records — better metadata will not help — [OPINION grounded in OWN-EXPERIMENT].
- Licensing unclear — RRUFF none, SciGlass ODbL title/MIT body, composites disclaimer only, MP "BY-C" — hurts redistribution of any consolidated dataset — [OWN-EXPERIMENT].

## 10. Jargon that matters for the big picture
- Information layer — one of 8 slots a record should fill (composition ... supported tasks); think feature-group completeness.
- Missing join — two tables about the same thing share no key; like datasets with no common id.
- Insufficient variation — a variable never changes in the data, so no model can learn its effect.
- Physical-model limit — label comes from an approximation (e.g. PBE DFT); systematic label bias.
- Convex hull / energy_above_hull — stability score relative to competing phases; depends on reference set and functional.
- GGA/PBE vs r2SCAN — older vs newer DFT approximations; like labels from two annotators with different bias.
- Enantiomorph / handedness — mirror-image crystal; same material, different space-group number.
- Fictive temperature / thermal history — how a glass was cooled; a hidden state variable.
- Processing route / microstructure — how a metal was made and its grain structure; the dominant hidden feature for strength.
- PSMILES — repeat-unit string for polymers; drops chain length and stereo.
- Mn/Mw/PDI — chain-length distribution statistics; method-relative.
- Runout — fatigue test stopped before failure; a censored label.
- R-value — min/max stress ratio defining the fatigue regime.
- Combinatorial library — one film with a composition gradient measured on a grid; many samples, little process variation.
- MAD baseline — Matbench's dummy-model error.

## 12. Smart or non-obvious ideas worth not losing
- Classify a material family by what must be specified beyond composition before two samples count as "the same"; each unrecorded dimension is a join no database can make.
- Split every gap into "documentation/linking fix" vs "needs new experiments" — 49 vs 9 (+14 both) of 72 — this is the low-hanging-fruit filter.
- A record complete in its own schema can still be useless for a task (row 1446: every column filled, still no S-N curve) — completeness is task-relative.
- Within-group label spread in source data (steels median 82.7 MPa; Tg SD 42.58 K) gives a noise floor for benchmark error — a cheap, publishable sanity check.
- Follow one material (alpha-quartz) through experiment -> DFT -> training frames -> benchmark -> candidate release to expose where ids, versions and functionals are lost.
