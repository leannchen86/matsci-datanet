## 5. Problems / gaps identified
- B1 (retitled): "Phase labels are interpretations whose disagreement has been measured, but whose error against independent measurement isn't stated." Hurts synthesis models, the "target made" reward, discovery claims — [SOURCE + OPINION].
- B2: negatives cannot be told apart from bad runs, inconclusive results or missing data; an unrecorded cracked tube or mix-up is unrecoverable by software. Internal side belongs to Periodic's process engineers/equipment AI; external value = cross-lab evaluation — [OPINION, SOURCE-supported].
- B3: property results lack detection limits (lowest temperature reached) and specimen-level attribution (which piece, its mass, its phases); extended to magnets; untouched by Periodic's posts. Hurts Tc models using negatives and hit verification — [OPINION + SOURCE].
- Reward, best-of-n selection and evaluation all pass through the same judge family; net bias unmeasured — [OPINION].
- FrontierXRD independence unstated (exclusion from training, judge calibration, harness-searchable lab records; >=14 evaluations on the same items) — [OPINION].
- Binary judged success hides phase fractions, minor-phase limits, abstention; scoring of unsolved/crashed items unclear — [OPINION].
- Cross-lab / cross-instrument transfer untested; supports the external-lab angle — [OPINION].
- Specimen retention decides feasibility; if specimens are gone only prospective collection works — [OPINION].

## 10. Jargon that matters
- XRD — fingerprint scan of a powder; phase ID = deciding which crystals made it (a labeling step).
- Phase — one distinct crystalline compound in a mixture.
- Rietveld refinement / Rwp — curve-fit of candidate phases; Rwp is training loss, not accuracy.
- Native vs .xy file — raw instrument file with settings vs stripped two-column export.
- Tc — superconducting transition temperature; "none down to 1.8 K" is a censored label.
- PPMS / MPMS — instruments for resistance / magnetization vs temperature.
- Orthogonal measurement (SEM-EDS, TEM, synchrotron, TGA) — a different instrument that can contradict the XRD reading.
- L0/L1/L2 — lab's label / blind re-analysis / independent measurement check.
- J vs J, J vs M — judgment-vs-judgment agreement vs judgment-vs-measurement accuracy.
- LLM judge as reward — RLHF-style proxy reward; Goodhart risk.
- Harness — tools + context around the model (lab records, structure DBs, fitting software).
- Best-of-n — sample n analyses, keep one; raises score and cost.
- Held-out chemical system — test split by element set; subsystems still leak.
- Retained specimen — the physical sample still exists and can be re-measured.
- Kappa — agreement corrected for chance; depends on the unreported success base rate.

## 12. Smart or non-obvious ideas worth not losing
1. Agreement is not accuracy: a benchmark scored by judges calibrated on experts cannot see errors the experts and judge share; only a different measurement can.
2. Seal the claim list (lab labels + open baseline) before the company runs its model, so its participation is optional and the set stays independent.
3. Sample random agreements, not only disagreements, with recorded selection probabilities, so shared errors and population rates are estimable.
4. Split "inconclusive" into evidence-limited vs analysis-limited; treat "no transition down to 1.8 K" as a censored label tied to specimen purity.
5. Test "raw beats summary" explicitly (native file vs strong summary, held-out batches, with/without context); deliver protocol + cost per checked claim as the asset.
