- Jha 2019 corrected (duplicates removed 1,963 → 1,643): 0.0715 vs 0.1325 eV/atom pretrained vs experiment-only; earlier "0.06 vs 0.13–0.15" — [REFUTED]. Pretrained with ~148 experimental compounds (0.106) beats from-scratch with ~1,479 (0.133). Jha never varied DFT size. — [SOURCE]

## 10. Jargon
- zT — TE figure of merit computed from Seebeck, resistivity, κ; a derived label you can recompute to catch errors.
- Power factor (S²/ρ) — intermediate derived quantity.
- DFT — quantum simulation giving "synthetic labels" (MP, OQMD, GNoME, JARVIS).
- Paper-grouped split — GroupKFold by DOI.
- Digitisation — reading numbers off published plots; the annotation step.
- Powder XRD pattern — 1-D fingerprint; phase ID = multi-label classification.
- Rietveld refinement — fitting a structure model to a pattern; gives phase fractions.
- Calculated vs measured profile — synthetic vs real sample.
- Known-answer (weighed mixture) — ground truth by construction.
- Multi-rater label set — inter-annotator agreement.
- Mirror copy (enantiomorph) — same crystal, opposite hand; a duplicate for powder XRD.
- thermo_type — which DFT recipe made an energy; label-version hazard.
- z′ score — error scaled by expected between-lab spread.
- Pre-registration — fix hypothesis and pass/fail metric first.
- Transfer gap — floor C in C + D·N^−α.

## 12. Ideas worth not losing
- Second curation as a null: two independent digitisations give a label-noise floor (0.55%) and an error detector; anything >10% apart is re-read, never averaged.
- Leak-report grouping unit differs by dataset: paper (TE), precursor + furnace run (synthesis), duplicate group + cross-archive hash (XRD).
- File-only lint: noise signature alone separates calculated from measured profiles (AUC 0.998).
- Separate error flags from provenance flags; put the tolerance in the rule id; add a "not evaluable" state; headline the strict rate.
- Count clusters (papers, runs), not rows; avoid preregistered checks that pass by construction.
