## 10. Jargon that matters for the big picture
- XRD (X-ray diffraction) — the fingerprint scan taken of every solid sample; the first check of "what did we actually make".
- Phase identification — deciding which crystalline compounds are in a sample from its pattern; like unmixing a signal into known sources.
- Multiphase sample — a mixture of compounds (here about 5 per hard pattern); makes the unmixing ambiguous.
- Rietveld refinement / Rwp — fitting a simulated pattern to the measured one; Rwp is the residual. Low Rwp is like low training loss: it can be overfit by adding phases.
- Harness — tools + databases + context wrapped around an LLM agent; here worth 3.8x.
- Midtraining — continued pretraining on domain material before RL ("knowledge injection").
- LLM judge / rubric reward — learned grader replacing a checkable reward; brings Goodhart risk.
- Verifiable reward — a reward checkable cheaply by code; XRD analysis is claimed not to be one.
- Inter-annotator agreement — 77.2% expert-vs-expert; the label-noise ceiling.
- Held-out chemical systems — test split by element combination; leaky because subsystems appear in training.
- A-Lab — Berkeley autonomous lab (Nature 2023) whose discovery claims were undermined by weak automated XRD analysis.
- PPMS/MPMS — instruments measuring resistivity, heat capacity, magnetism; needed to detect superconductivity.
- Meissner effect — magnetic proof of superconductivity; needed with zero resistance and independent replication.
- GNoME — DeepMind's computed-candidate materials project led by Çubuk.
- COD / Materials Project / BGMN — open crystal-structure database / computed-materials database / open Rietveld engine (the "open tools" baseline).

## 12. Smart or non-obvious ideas worth not losing (<=5)
- "Ladder of rewards": superconductivity is too sparse a reward, so build dense verifiers bottom-up (did we make it -> does it show the property -> is it new). XRD phase ID is rung one, which is why it shipped first and why XRD label quality is foundational.
- The measured moat is harness + lab data at inference time (3.8x), not model weights; the model is the most replaceable layer, and generalist models erase leads on literature-rich tasks every few months.
- In XRD, "good fit" is not "correct answer"; fit-metric labels can be gamed, and expert labels agree only about 77%. Any XRD benchmark must report label noise and error bars (n=134 gives about +/-8.5 points at 95%).
- Lab data should matter most where public knowledge is thin (synthesis planning, retry decisions, experiment selection); there is no public benchmark there.
- Reading a company's cumulative-gains chart as a history of what broke (fit reward -> judge; text -> images; short -> long context; RL-only -> midtraining) is a reusable way to infer unpublished failures.
