B. Web research (verified 2026-09-15)
- RRUFF = free mineral reference DB, Univ. of Arizona (Robert Downs group), since 2006; Raman/IR/powder XRD/microprobe on characterized specimens; 9,858 samples, 4,349 public; 6,187 IMA minerals; funders NSF, NASA JPL, private sponsor; no explicit data licence, no PIDs — [SOURCE].
- Remakes exist for nearly every case but almost none fills the old records. Four kinds: fix going forward (RRUFF writes Raman wavelength into headers since 2025-10-02, default "unknown"); repackage/clean (opXRD 1,290 RRUFF patterns, AI4Spectro, RamanBench; GlassNet 281,093 -> 218,533; SciGlass Next, Jena, beta 2024 -> v0.9.0 2026-02-13, fixed 2,360 glass-number ranges, API + MCP server); text-mine (MatSKRAFT 535,643 entries, composition F1 71%, v2 is CC BY-NC-ND; Ceder 31,782 + 9,518 reactions); new designed dataset (RSDB 2026 re-measures top 600 minerals; Raj 2026 396 MPEA conditions ~9% of literature; Texas A&M Hall-Petch 94 conditions, single-pass unverified) — [SOURCE].
- Why: "a calculation can be rerun… A setting nobody wrote down can't be recovered" — computed sets get recomputed (MP v2026.04.13: r2SCAN recompute ~26% done, ~26k phonons, 74,052 GNoME materials, ~117k total; OMat24 ~118M calcs, 400M+ core hours; MatPES; MP-ALOE 909,792; Alexandria 30.5M), experimental ones get cleaned — [SOURCE]+[OPINION].
- Complete-by-design exemplars: NIMS data sheets (fatigue since 1978, creep since 1966, longest creep test 350,771.8 h), NIST AM Bench; ICDD pattern-quality grants are the main paid re-measurement programme ($1,000 for 5 patterns; ICDD takes copyright) — [SOURCE].
- Round robins show why uncertainty matters: thermoelectric ZT 19% relative uncertainty across labs (Alleno 2015); NIST CO2 isotherm 6 of 13 datasets outside consensus; DSC Tg ~3-4 °C between labs (EMPA, 28 participants) — [SOURCE].
- Cost/time anchors: composite moisture equilibrium 1,150-5,100 h, salt water 6-8 months, one 10^7-cycle runout ~29-116 days at 1-4 Hz (estimate/upper range; ~12 days at ~10 Hz); ALBA industrial beamtime €543.84/h; NSF DMREF $1.5-2.0M/4 yr; PDB ~$420 per structure; EcoCyc $219 per curated paper; A-Lab 36 of 57 targets in 17 days with a Nature correction Jan 2026 (earlier figure 41 of 58) — [SOURCE].

## 5. Problems / gaps identified

FAIR does not require completeness or uncertainty; no cross-materials survey of how often uncertainty is reported — [SOURCE].
- No cross-database identifiers (RRUFF 0 external ids; SciGlass 45,293 blank DOIs; benchmark rows stripped of MP ids) — hurts dataset joining/dedup/leakage checks — [OWN-EXPERIMENT].

## 10. Jargon that matters for the big picture
- Record Wall — 9 records x 8 layers grid of present/partial/absent; like a data-card audit per dataset.
- Gap types: obs (not measured/recorded/released), def (undefined field/unit), join (no key to link tables), unc (no error bars), var (too little variation to learn from; a covariate-coverage problem), model (physics of the calculation is the limit).
- doc fix vs new-data fix — metadata/labelling work vs collecting new samples.
- RRUFF — mineral spectra reference library; like a labelled reference set with weak metadata.
- SciGlass / MPEA / matbench_steels / HTEM / PolyMetriX — glass, high-entropy alloy, steel, thin-film, polymer-Tg tables used as ML datasets.
- Matbench — ML benchmark suite built from MP and others; drops source ids (no provenance column).
- MPtrj / CHGNet — DFT trajectory training set and the interatomic-potential model trained on it.
- r2SCAN vs PBE — more vs less accurate DFT "labelling function"; recompute = relabel.
- Round robin — many labs measure the same sample; inter-annotator agreement for instruments.
- Runout — fatigue test stopped without failure; a right-censored label.
- NeXus / NXraman — standard file schema that stores instrument settings with the data.
- ICSD / COD — paid vs open crystal-structure databases.
- esd — estimated standard deviation from a structure refinement (the error bar that gets dropped).
- Tg / DSC — glass transition temperature and the calorimetry used to measure it; value depends on protocol.
- Enantiomorph (#152 vs #154) — mirror-image crystals that get different space-group numbers, breaking naive joins.

## 12. Smart or non-obvious ideas worth not losing
- Gap TYPE is a cost predictor: join 4% -> var 83% need new data. A software-only team should target join/def gaps (the 49 doc-only rows) first.
- Software-only low-hanging fruit already identified with exact targets: Matbench->MP id sidecar; MPEA qualifier/± restoration (382 + 264 cells); SciGlass DOI back-fill (45,293 refs); HTEM absorption bug validator; MP uncertainty fill from existing pymatgen values; handedness-aware structure matcher.
- Computed uncertainty was never produced; experimental uncertainty was produced then dropped at handoffs — different fixes (UQ methods vs lossless export pipelines).
- Information loss is a pipeline property (instrument -> file -> summary -> benchmark -> copy); a "handoff linter" at each stage is more general than fixing any one database.
- Agreement between SciGlass and INTERGLAD is not independent validation (shared Mazurin handbook sources); Mazurin: 4-8% of compiled points defective, detection needs 8-10 independent sources.
