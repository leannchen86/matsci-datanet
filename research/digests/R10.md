## 4. Findings (each: claim — numbers/evidence — [STATUS] — plain-language "so what")
- H1 FAILED: not enough "hard" multiphase patterns for a full eval set — "hard" = fitted answer has >=4 phases at >=1 wt% each (the plan's own cutoff, not a standard term). PG 157/1,035 samples + GPSS 10/352 = 167; full set needs 270; pilot range is 50-269. Counting every phase with weight >0 gives 168 + 14. Dara pairwise answers top out at 3 phases. PG counts only fits a person scored 1 or 2 (3 = poor). [OWN-EXPERIMENT] — So what: a multi-rater benchmark can start only as a 167-pattern pilot; reaching 270 needs new multi-precursor reactions or another source.
- H2 HELD with caveats: answers disagree often — where one PG scan has both a manual and an automated fit, phase sets differ in 316/343 scans; human adds phases in 227, removes in 5. Caveats: people likely re-fit only the bad fits (not a random sample), and all 1,216 of 1,216 non-empty PG verifications carry one editor ID. [OWN-EXPERIMENT] — So what: this is machine-vs-human disagreement, NOT inter-rater disagreement; neither release has independent raters, so keep >=3 independent raters and keep every label.
- H3a HELD: handling (humidity, air exposure, storage) is not recorded anywhere — none of PG's 115 field paths covers it; 13 handling words (air, humid, glovebox, storage...) get 0 hits in PG free text; scan file headers empty in 1,417/1,417 PG and 352/352 GPSS files. [OWN-EXPERIMENT] — So what: a handling-history schema starts from zero fields.
- H3b HELD for PG / partial for GPSS: synthesis-to-XRD delay can't be derived — PG: scan start time in 1,351/1,351 scans, absolute synthesis time in 0/1,035 samples. GPSS: database record creation time works as a proxy (inference): median 3.0 days to XRD, range 1.0-36.2, n=352. [OWN-EXPERIMENT] — So what: a lab system can stamp this automatically; make it a required field.
- H4 HELD for outcomes / gap for scans: failures are logged as richly as successes — PG has 369 unreacted, 113 partially reacted, 26 physical failures; heating temperature filled in 345/369 unreacted vs 135/143 fully reacted. But of five scan statuses in the schema only "valid" appears (1,351/1,351). [OWN-EXPERIMENT] — So what: PG negative outcomes are reusable now; failed scans may have been filtered out (ask authors).
- H5 HELD: phase labels can't join open databases — PG: 745/755 labels carry ICSD ids, 0 carry COD or Materials Project ids. GPSS: 334/687 CIF files are ICSD; 311 are custom spinel.cif (P1, disordered). Dara reference fits use ICDD cards and ICSD codes. [OWN-EXPERIMENT] — So what: labels are keyed to paywalled databases; a crosswalk to open ids is a prerequisite for any redistributable set; custom spinels need structure matching (no id).
- H6 HELD, READING REVISED: pymatgen StructureMatcher merges left- and right-handed quartz — alpha-quartz COD 1011097 (P3_1 21) matched its exact mirror (P3_2 21 per spglib) at RMS 0, at defaults and all 6 variants; real opposite-hand COD pairs also matched: Se (RMS 0.017), Y2Ge2O7 (0.009). Cause: it accepts left-handed lattice bases and no setting disables that (blocking them in memory makes the mirror match fail while same-hand still matches). [OWN-EXPERIMENT]. [REFUTED reading]: initially framed as a matcher error; corrected — for randomly oriented powder XRD either hand gives the same pattern (even with resonant scattering), so merging hands is CORRECT for powder XRD; exceptions are textured samples and single-crystal methods. Exposure: 91/1,035 PG samples have a fitted phase in a mirror-pair space group; GPSS 0/687 phases; one PG manual fit uses both hands of GeO2 at once (54% and 14%, PG_1624, second scan, not the active one). GeO2 #152 appears in 24 samples, #154 in 1. — So what: the scorer must count both hands as one phase and say so.
- H7 INCONCLUSIVE: 20 weighed mixtures can't rank methods — Dara 38/40 (95% interval 87.5-100); Jade 35/40 (77.5-95.0); half-widths 6.2 and 8.8 fall between pre-set cutoffs of 5 and 10; paired difference 7.5 points, interval 0.0-15.0. All Dara errors and 4 of Jade's 5 are on 2-minute scans; 8-minute scans near ceiling (20/20, 19/20). Bootstrap resamples mixtures (both scan times together), 10,000 resamples. [OWN-EXPERIMENT] — So what: the weighed set needs harder items, not just more items.
- Exploratory: long-gap re-scans change the answer — 183 of 184 PG samples scanned twice >180 days apart were first scanned 2024, re-scanned 2025-26. Same-method fits: phase set changed in 105/136 (77%) with gap >180 days vs 12/25 (48%) with gap <=30 days. Some look like air exposure (inference): carbon-free samples gained Ag2CO3 at 23-25 wt% (PG_0118, PG_0139), Li2CO3 at 13 wt% (PG_1224). Some can't be real: Y4C7 at 31 wt% (PG_3850), graphite at 66 wt% (PG_1516) in carbon-free oxide systems, both from automated fits scored 3 or unscored. Across 921 fits of carbon-free samples, carbonates appear 81 times (68 in human fits); the other 13 carbon phases (carbides, graphite) all from automated fits. In 115/184 the official outcome comes from the earlier scan. [OWN-EXPERIMENT, exploratory] — So what: aging and refinement drift are indistinguishable without handling history; this is the concrete test case for the schema.
- Exploratory: no fitted phase uses an element outside precursors or air — 0/3,240 phases at >=1 wt%; control (swap in another sample's precursors) flags 1,642. Inference: fits never consider crucible/holder contamination. An element rule alone misses the impossible carbides, so a plausibility rule is also needed. [OWN-EXPERIMENT, exploratory]
- Exploratory: default matching merges different phases and splits identical ones — alpha-quartz (COD 1011097) matched beta-quartz (COD 1011200) at RMS 0.169 though (101) peak is 26.67 vs 26.21 deg 2-theta (Cu K-alpha); stol <=0.15 separates them. Older COD files declare oxidation states (Te0, Hg2+, S2-), AMCSD-derived ones don't, so the default comparator rejects the same Te structure (matches at RMS ~0 once labels ignored). PG fits beta-quartz-type SiO2 #180 in 20 samples; a default scorer would count it as alpha-quartz. [OWN-EXPERIMENT, exploratory]
- Scoring-rule evidence from Dara/Jade: formula spelling alone (BiVO4 vs VBiO4) flips 3/20 of Jade's verdicts; composition-only matching credits Dara's wrong Y2O3 polymorph; patterns listing a phase twice still marked correct in 4/4 Dara and 2/3 Jade cases; 2 of 20 pairwise reactions are ambiguous on "unknown phase". [OWN-EXPERIMENT]

## 5. Problems / gaps identified in the field or in the data (each: gap — evidence — who it hurts — [STATUS])
- No independent multi-rater XRD labels exist in open releases — one editor ID on 1,216/1,216 PG verifications — hurts anyone wanting label-noise/agreement ground truth. [OWN-EXPERIMENT]
- Too few hard multiphase patterns in the open — 167 vs 270 needed — hurts benchmark builders. [OWN-EXPERIMENT]
- Handling history and synthesis-to-XRD time absent — 0 fields, 0 keyword hits, empty headers — hurts anyone separating sample aging from fit drift (77% vs 48% re-scan change). [OWN-EXPERIMENT]
- Phase labels locked to ICSD/ICDD (paywalled) — 745/755 PG, 0 COD/MP ids; 311 id-less custom spinel CIFs — blocks redistributable datasets and cross-dataset joins. [OWN-EXPERIMENT]
- Weighed-truth benchmarks are too small and too easy — 40 scans, ceiling at 8-min scans, methods inseparable — hurts method ranking. [OWN-EXPERIMENT]
- Default structure-matching tooling is unsafe for scoring — merges alpha/beta quartz, splits identical Te over oxidation-state labels. [OWN-EXPERIMENT]
- Automated fits produce chemically implausible phases (carbides/graphite in carbon-free oxides); fits never consider contamination elements. [OWN-EXPERIMENT, partly inference]
- Public answers leak: PG, GPSS, Dara answers are all public, so they can't be a hidden test split; CC BY data can't carry evaluation-only terms. [OPINION/SOURCE-licence reasoning]
- Failed scans possibly filtered out of PG (only "valid" status). [OWN-EXPERIMENT; cause unknown]
- Dataset record errors (see section 6, "Upstream error reports").

## 10. Jargon that matters for the big picture
- XRD (powder X-ray diffraction) — a 1-D "fingerprint" signal of a powder; the task is to say which crystal phases are in it (multi-label classification plus fractions).
- Phase — one distinct crystalline compound/structure in a sample; "multiphase" = mixture.
- wt% — weight fraction of each phase; the regression target.
- Fit / refinement (Rietveld) — the model-fitting step that turns a pattern into phases + fractions; the "label".
- Hard pattern — this plan's cutoff: >=4 phases at >=1 wt% each.
- Weighed mixture — powders mixed at known weights; the only true ground truth (like synthetic labels with known answer).
- ICSD / ICDD vs COD / Materials Project — paywalled vs open crystal-structure databases; ids are the join keys.
- Crosswalk — id mapping table between databases.
- CIF — crystal structure file format.
- Space group / polymorph — same formula, different crystal arrangement (alpha vs beta quartz); distinct classes.
- Enantiomorph ("hands") — mirror-image structures; indistinguishable by powder XRD.
- StructureMatcher / stol — pymatgen's structure-equality test and its site tolerance; the "equality function" of a scorer.
- Handling history — what happened to a sample between synthesis and measurement (air, humidity, storage time); missing metadata/covariate shift.
- Dara / Jade — automated vs commercial phase-identification tools compared on the Dara benchmark.
- NeXus — existing scientific data format/standard the schema should map onto.

## 12. Smart or non-obvious ideas worth not losing (<=5)
- The 184-sample PG re-scan set (77% vs 48% phase-set change) is a ready-made acceptance test for any handling-history schema: can the record separate aging from refinement drift?
- The scorer's equality function is itself a research artifact: formula spelling flips 3/20 verdicts; defaults merge alpha/beta quartz; hands should be merged for powder. A small open "XRD scoring library" is low-hanging and needed by every benchmark.
- Cheap plausibility linting (carbides/graphite in carbon-free systems; element-set check with a shuffled-precursor control: 0/3,240 vs 1,642) catches bad automated fits at zero lab cost.
- Benchmark design for difficulty, not count: errors concentrate in 2-minute scans; 8-minute scans hit ceiling.
- A data-quality error report to PG/GPSS/Dara/COD authors is an immediate, credible contribution needing only the user's approval.
