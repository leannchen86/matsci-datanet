## 10. Jargon that matters for the big picture
- Target phase — the specific crystalline compound you were trying to make; "not obtained" = synthesis failed, so nothing was tested (like a training example whose input never existed).
- Tc — superconducting critical temperature; Tc = 0 used in datasets as "not a superconductor" label.
- Negative result / bounded negative — "no effect seen"; bounded = with the detection limit stated (down to X kelvin, at Y pressure).
- Pre-registration — writing predictions and scoring rules before looking at data (like fixing the test set and metric before training).
- Wilson interval — confidence interval for a proportion that behaves well for small n.
- SuperCon (NIMS) — main public database of superconductors; source for most ML Tc datasets.
- 3DSC — dataset joining SuperCon entries to Materials Project crystal structures (5,759 matched).
- Stanev 2018 — widely used ML-for-Tc paper/dataset (composition + Tc only).
- Label noise — wrong labels in training data; here, "never made" recorded as "Tc = 0".
- M/S/F/J evidence types — the brief's tagging scheme; F/J = fit/judgement, i.e. interpretation rather than raw measurement.
- [P]/[G]/[H] tags — provenance tags from the brief; [P] = Periodic's own public statements.
- LLM judge agreement vs correctness — scoring a model by agreement with another model/experts, not with ground truth.
- Intercalation (the dropped arrows) — inserting atoms/molecules between layers of a host material; the arrow notation was lost in text extraction.
- High-pressure phase — material state that only exists/superconducts under pressure; a condition missing from negatives.

- A label-provenance audit is a solo, laptop-scale contribution: trace one famous negatives table through Stanev 2018 into 3DSC and measure what fraction of "Tc = 0" training labels are actually "never synthesised" (prediction >=10%; <3% would exonerate the dataset builders). - Distinguish three kinds of "negative": never made / made but unbounded measurement / made and bounded. Only the last is a real negative label.
- Pre-register + adversarial second-pass agents for literature cross-checks: turns LLM literature search into something falsifiable.
- The source often DOES record the distinction; the loss is downstream — so the intervention is a re-extraction/patch to existing public datasets, not a new schema or lab.
