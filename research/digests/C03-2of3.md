## 4. Findings
**TE composition-only baseline (Starrydata, 300 K, kNN-5 on element fractions, md5 5-fold)**
- Random splits leak papers — Seebeck S: n=12,222 samples, 3,015 papers, 2,419 chemical systems; median relative error 25.5% random vs 42.2% grouped-by-paper vs 46.6% grouped-by-chemical-system; in the random split 93.5% of test papers are also in training (composition seen 40.4%). Resistivity ρ (n=12,158; 3,045 papers): 0.2365 -> 0.3589 -> 0.3659 decades — [OWN-EXPERIMENT] — a random train/test split is like splitting video frames of the same clip; honest TE benchmarks must hold out whole papers.
- The composition string does not identify the label — 647 compositions appear in 2+ papers (21,856 paper pairs): median between-paper S difference 32.7%; only 35.6% of pairs within 20%; opposite sign in 3,881/21,856 = 17.8%; within the same paper the median is 12.9% (5,161 pairs). ρ: 630 compositions, 22,548 pairs, median 0.346 decades, 45.7% within factor 2 (within-paper 0.144 decades). Bi2Te3: 111 papers / 222 samples, paper medians -241 to +280 µV/K; CoSb3 44 papers, -622 to +245 — [OWN-EXPERIMENT] — the "class name" (formula) is an ambiguous key; dopant/carrier type/processing are missing.
- Lookup beats the model; irreducible floor is high — on the 3,593 paper-held-out samples whose composition exists in training papers: same-composition median lookup 22.9% error vs kNN paper-grouped 29.4% vs kNN random 24.8%; even with answers known (one value per composition) 15.0% (14.2% on the 3,817-sample "other papers" set; only 58.0% within 20%). ρ: lookup 0.261 vs kNN 0.311 vs floor 0.179 decades (3,696 samples) — [OWN-EXPERIMENT].
- Spread is between specimens, not instruments — round robins circulating one specimen give S between-lab uncertainty 6% (1σ, Alleno 2015) or 5.7-7.9% (2σ, half-Heusler) vs 32.7% between papers — [SOURCE + OPINION/inference] — composition-only models are capped well above metrology noise; specimen descriptors are required.

## 10. Jargon that matters
- Seebeck coefficient S / resistivity ρ / thermal conductivity κ / zT = S²σT/κ — the TE "labels"; zT compounds the noise of three measurements.
- Round robin — many labs measure the same specimen; the field's inter-annotator agreement study.
- Reference material (NIST SRM 3451/3452, BCR-724) — a calibration sample with certified value; like a gold-label probe item.
- z′ score (ISO 13528) — prediction error divided by lab spread plus reference-value uncertainty.
- Grouped-by-paper split — GroupKFold by DOI; prevents leakage.
- "Answers-known floor" — best possible error if one value per composition were chosen with test labels visible; irreducible label noise for that input.
- Specimen vs composition — the physical sample (processing, density, doping) vs its formula; formula is an underspecified key.
- Matbench — standard ML benchmark suite; several tasks are MP-computed labels.
- Materials Project (MP) / GNoME — DFT-computed databases; PBE vs r2SCAN are calculation recipes that change labels.
- OPTIMADE — keyless public query API across materials databases.
- Enantiomorph / mirror copy — left- and right-handed versions of one structure filed under two space groups; duplicates for joins.
- Starrydata / teMatDb / ESTM — TE datasets digitized from paper figures.
- Pre-registration + adversarial verifier — write the expected result first, then a second agent tries to break it.
- Censoring qualifier — ">300" stored as 300; silently turns a bound into a value.

## 12. Smart or non-obvious ideas worth not losing
- The "answers-known floor": measure irreducible label ambiguity of an input representation before building any model (15% for composition-only S).
- Compare between-paper spread (33%) with single-specimen round-robin spread (6%) to separate "specimens differ" from "instruments differ".
- Score on unaveraged member records, not just averaged benchmark rows; how much error is hidden depends on the model (RF yes, ridge no).
- Every experiment gets a written prediction and a second agent that reruns it; also check that each test can actually fail.
- Turn every report gap into a regression-testable number (first milestone = "one command reproduces the count"), which makes the builds verifiable and small.
