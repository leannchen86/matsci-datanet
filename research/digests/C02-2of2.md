## 10. Jargon that matters for the big picture
- XRD pattern — the diffraction fingerprint of a powder; the input whose "label" is the list of crystal phases present.
- Phase / multiphase — one crystalline compound in a sample; >=4 phases is the hard, multi-label case.
- Refinement (Rwp) — fitting candidate structures to the pattern; Rwp is the fit loss.
- Enantiomorph / handedness (space groups #152 vs #154) — mirror-image crystals with identical powder patterns; a join trap.
- DFT / PBE — simulated (0 K) properties; PBE systematically over-estimates volume.
- zT — thermoelectric figure of merit computed from S, rho, kappa and T; recomputing it is a free consistency check.
- Round robin — many labs measure the same specimen; yields the label-noise floor.
- Provenance / lineage — where a row came from (source id, version, processing).
- Specimen schema — required fields for one physical sample record (a datasheet for a datapoint).
- Blind test (CASP-style) — labels hidden until after predictions; leak-proof test set.
- Known-answer case — a sample whose truth is set by construction (weighed mixture); a unit test for analysis tools and judges.
- LLM judge — a model grading free-text analyses; needs calibration against experts.
- Censored value — ">300" stored as 300; a truncated label.
- Pre-registration — fix pass/fail criteria before looking at results.
- OPTIMADE — common query API across structure databases.
