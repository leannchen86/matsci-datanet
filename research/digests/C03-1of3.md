## 10. Jargon that matters for the big picture
- zT — thermoelectric figure of merit, S^2*sigma*T/kappa; the "label" everyone reports.
- Seebeck S / sigma / rho / kappa — voltage per kelvin / electrical conductivity / resistivity / thermal conductivity; the three measured inputs to zT.
- Self-consistency (Sc-ZT) check — recompute zT from its inputs and compare; like checking a label against a checksum.
- Round robin — many labs measure the same sample; gives the label-noise floor (inter-annotator agreement).
- SRM — NIST certified reference sample; a calibration "unit test" for instruments.
- Specimen vs composition — the physical piece (with processing history) vs its chemical formula; formula alone is like a filename without the file.
- Fill rate — share of records where a schema field is actually populated.
- Null codes — distinct reasons a value is missing (unknown, not measured, not released...); not all NaNs are equal.
- Gap effect closes/partial/exposes — whether a schema actually fixes a gap, partly fixes it, or only makes it visible.
- Grouped split (by paper / chemical system) — hold out whole sources to avoid leakage, like splitting by patient not by scan.
- Blind test / hidden labels — CASP/ILSVRC-style evaluation on unseen answers.
- Digitized data — numbers read off published plots.
- z / zeta score (ISO 13528) — scoring a result against reference value and its uncertainty.
- FAIR / wh- questions — metadata principles: who, what, when, how for each record.

## 12. Smart or non-obvious ideas worth not losing
1. A physics identity (zT from S, sigma, kappa) is a free, automatic label check — the materials analogue of ImageNet's "cheap label verification"; range checks alone miss 587 of 646 gross failures.
2. Digitization noise (~0.5-1%) << inter-lab noise (15-20%): literature-mined pools are fine for TRAINING; the test set must be new, replicated, unpublished measurements scored against between-lab spread.
3. Composition is not identity: split and key by specimen/paper; random splits leak (93.5% of test papers seen) and nearly halve apparent error.
4. Start the blind benchmark with S(T) and rho(T) (fast, SRM-anchored), add kappa/zT later with >=2 labs.
5. "Closes a gap" must mean a compliant dataset would actually carry the information — adding an empty slot only "exposes" the gap; the verifier caught 37 such over-claims.
