# R02 — Record Wall Debrief (where materials data is missing, who has tried to fix it, what fixing costs)

## 1. What this slice is (2-3 plain sentences)
- A published "session debrief" report dated 15 Sept 2026, written as a follow-up to an earlier report called "Materials Record Wall". That earlier report scored 9 hand-picked materials data records (3 computed, 6 experimental) on 8 "information layers" and listed 72 named gap rows (`case#n`).
- This debrief (a) recomputes patterns from that report's own gap coding, (b) explains RRUFF and surveys whether anyone has "remade" the incomplete datasets, (c) estimates resources and bottlenecks for closing gaps, and (d) maps every one of the 72 gap rows to an action and an owner.
- Two evidence bases: tallies over the report's own tags (small, author-coded sample) and a multi-agent web research run "checked against sources on 15 Sept 2026".

## 4. Findings (each: claim — numbers/evidence — [STATUS] — plain-language "so what")
Caveat on all tallies: they describe how the report author coded 9 hand-picked records, "indicative, not field-wide statistics".
- F1. Numbers are there, context is not — signal layer fully present in 5 of 9 records; uncertainty absent in 6 of 9; provenance only partial in all 9; processing, structure/state, uncertainty, provenance fully present in 0 of 9 — [OWN-EXPERIMENT, tally of own coding] — labels exist, but the metadata an ML person needs to trust/join them does not.
- F2. Most gaps are paperwork — of 72 gap rows: 49 documentation only (68%), 14 documentation + new data, 9 new data only; so 23 need new measurements/calculations, 18 of those 23 in the six experimental records — [OWN-EXPERIMENT] — a large share of fixes needs no lab.
- F3. Gap type predicts cost — share of rows needing new data: missing join 4% (of 23 rows), missing definition 12% (of 41), missing uncertainty 50% (of 14), physical-model limit 73% (of 15), missing observation 76% (of 17), insufficient variation 83% (of 12). Rows carry several tags so counts sum to >72. 96% of join gaps need documentation only — [OWN-EXPERIMENT] — linking/ID work is the cheapest category; variation/observation gaps are the expensive ones.
- F4. Lost at hand-offs — 21 of the 106 status marks in the gap tables are "not in public release" (existed upstream, dropped before publication). Examples: RRUFF "RAW" files are already processed; SciGlass summary table drops errors, temperature ranges, methods and truncates refractive index; Matbench drops MP ids and build version; matbench_steels averages 842 records into 312 rows; the MPtrj parquet copy lacks energy_per_atom (the label CHGNet was trained on) — [OWN-EXPERIMENT, from Record Wall file inspection] — benchmark packaging itself destroys information.
- F5. Computed vs experimental fail differently — computed: of 24 cells, 8 present, 4 absent, 2 n.a., 10 partial (42%); experimental: 40 of 48 cells partial (83%). Computed cases get more missing-join tags (47% of their rows vs 26%) and model-limit tags (32% vs 17%); experimental get more missing-observation (28% vs 11%). Uncertainty: computed never produced it (MP `energy_uncertainy_per_atom` is null — field name misspelled, build code never fills it, pymatgen already computes the value); experimental had it and lost it (RRUFF errors in refinement output not headers; SciGlass error columns not in summary table; alloy table deleted ± from 264 cells) — [OWN-EXPERIMENT].
- F6. Expensive gaps cluster — definition gaps most common (57% of rows = 41/72); obs + var + model co-occur about 2x chance; obs+def at one fifth of chance, var+def under one third — [OWN-EXPERIMENT] — rows with labelling problems are mostly not the rows needing lab work.
- F7. Zero/blank are overloaded — "0" has 8 meanings across 5 cases (true zero, below detection, unrecorded setting, SD of a single measurement); composites blanks = not measured / n.a. / not reported / failed; runouts written Runout/runout/RO across 3 columns; alloy table turned ">300" into 300.0 and "150-200" into 175.0 so 382 cells look exact — [OWN-EXPERIMENT] — censored labels silently become exact labels.
- F8. Links work inside a DB, not between — RRUFF's 37 files carry no ICSD or MP ids; SciGlass DOI field blank in all 45,293 references; polymer DSC and SEC files share no sample id; space group fails as a join key for quartz (mirror forms #152 and #154) — [OWN-EXPERIMENT].
- F9. "Partial" takes four forms (named without settings, e.g. "PBE" only; covers only some rows, e.g. grain size in 237 of 1,545 rows; present but not in a data field; present but degraded) — from reading the 50 partial cells, not counted — [OPINION/reading].
- F10. Remakes repackage, almost none refill — computed datasets get recomputed (MP r2SCAN recompute ~26% done, ~26k phonon records added; OMat24 ~118M calculations; MatPES, MP-ALOE, Alexandria; MP independently recomputed ~117k GNoME materials; DeepMind training configs still "upcoming"). Experimental ones get cleaned, text-mined, or replaced: opXRD, AI4Spectro, RamanBench repackage RRUFF; RSDB (2026) re-measures top 600 minerals on verified museum specimens with instrument settings (closest to a true remake, but a new library); SciGlass Next (Jena, beta since 2024) cleans; MatSKRAFT mined 535,643 values from papers; a 2026 MPEA dataset adds processing for 396 conditions (~9% of the literature); HTEM is decaying (public libraries stop at 2019, raw-file downloads error, GitHub repos archived June 2026); steels: nothing found; polymer Tg: PolyMetriX is itself a merge of 9 sources — [SOURCE].
- F11. Round robins are the practical route to uncertainty — thermoelectric ZT 19% relative uncertainty across labs; 6 of 13 CO2 adsorption datasets outside a NIST consensus; DSC Tg differs ~3-4 °C between labs (EMPA study, 28 participants) — [SOURCE].
- F12. Cost/time anchors — composite moisture soak 1,150-5,100 h at 50 °C, salt water 6-8 months; 10M-cycle runout at 1-4 Hz = 29-116 days of machine time (upper range; ~12 days at ~10 Hz; own arithmetic), no price per coupon found; NIMS longest creep test 350,771.8 h (~40 years); OMat24 >400M core hours; A-Lab made 36 of 57 targets in 17 days, with a Nature Jan 2026 correction after manual re-analysis; ALBA industrial beamtime €543.84/h; NSF DMREF $1.5-2.0M over 4 years; ICDD starter grants up to 5 patterns for $1,000; curation analogues only from biology (PDB ~$420 per structure, EcoCyc $219 per paper) — [SOURCE; runout arithmetic OWN estimate].
- F13. RRUFF facts — free mineral reference DB, Downs group, Univ. of Arizona, since 2006; funded by NSF, NASA JPL, a private sponsor; 9,858 samples, 4,349 public; no licence stated; cite Lafuente, Downs, Yang & Stone (2015); since Oct 2025 headers carry a Raman-wavelength line (default "unknown") — [SOURCE].

## 5. Problems / gaps identified in the field or in the data (each: gap — evidence — who it hurts — [STATUS])
- G1. Unrecoverable gaps in existing records — crystal_expt#4 (Raman settings, probably 2006-08), crystal_expt#9 (1980 COD intensity data), glass#4 (thermal history), metal#7 (raw EBSD patterns, ~26 GB per scan, routinely deleted), composite#8/#10/#11, most of polymer#2 (Mn/Mw), ml#2 (CHGNet split from an unseeded shuffle) — hurts anyone wanting reproducible benchmarks or re-analysis — [SOURCE + OPINION]. Only route: a new dataset designed complete.
- G2. Owner-only fixes with absent owners — epam/SciGlass untouched since 2019; NREL-to-NLR rename broke every htem.nrel.gov link; MPEA repo archived (2024; Nov 2024); Open Citrination decommissioned — [SOURCE].
- G3. Licence/access walls — ICSD paid; NIMS PoLyInfo bans scraping; GNoME non-commercial; MatSKRAFT v2 forbids derivatives; VASP POTCARs not shareable; RRUFF no licence; SciGlass licence file titled ODbL but contains MIT text (2022 question unanswered); DOE/MSU none — hurts ML reuse and redistribution — [SOURCE].
- G4. No credit/incentive — 69.2% of researchers say too little credit for sharing data (State of Open Data 2025); a 2025 perspective found no standards/incentives for reproducibility studies; only about a quarter of authors answered requests for missing glass details — [SOURCE].
- G5. Missing standards — NeXus has no accepted definition for XRF quantification or four-point probe (also sputter deposition); no certified PLA molar-mass reference; NIST SRM 2245 expired — [SOURCE].
- G6. Values stuck in figures — in one alloy-extraction study 30.9% of values GPT-4 missed appeared only in figures — hurts text-mining pipelines — [SOURCE].
- G7. Copies spread problems — new composite databases copy DOE/MSU conventions; fixing Matbench labels would likely break comparability with past leaderboard scores (labelled an inference) — [OPINION].
- G8. No agreed uncertainty model for some quantities — MP correction uncertainties cover only fit error; none found for energies mixing DFT functionals — [SOURCE].

## 10. Jargon that matters for the big picture
- Record wall — 9 records x 8 metadata layers completeness grid; like a datasheet audit for datasets.
- Information layers — composition, processing, structure, method, signal, uncertainty, provenance, supported tasks.
- Gap types obs/def/join/unc/var/model — missing observation / definition / join key / uncertainty / variation / physics-model limit.
- Missing join — no shared id across databases; like tables with no foreign key.
- Insufficient variation — too few specimens/conditions; like a training set with no coverage of a covariate.
- RRUFF — verified-specimen mineral spectra library (Raman, IR, powder XRD).
- Round robin / interlaboratory study — many labs measure the same sample; gives label-noise estimates.
- r2SCAN vs PBE — more accurate vs standard DFT "functional" (simulation recipe); mixing them is like mixing label sources with different bias.
- Hull distance — computed stability score relative to competing phases.
- Runout — fatigue test stopped without failure; a censored label.
- DSC / Tg — calorimetry method / glass-transition temperature; depends on heating rate and water.
- EBSD — electron-diffraction microstructure maps; raw patterns ~26 GB per scan.
- NeXus / Bluesky — file-format standard / data-collection framework that record settings at acquisition.
- IGSN — persistent id for a physical sample.
- Matbench / MPtrj / CHGNet — ML benchmark suite / DFT trajectory training set / model trained on it.

## 12. Smart or non-obvious ideas worth not losing (<=5)
1. Gap type predicts fix cost: joins/definitions are near-free (4%/12% need new data); variation/observation are lab-bound (83%/76%). Prioritise by tag.
2. Uncertainty goes missing for opposite reasons: computed data never produced it; experimental data had it and lost it at export — so experimental uncertainty is partly recoverable by re-exporting upstream files.
3. Information is destroyed at hand-offs (instrument->file->summary->benchmark->copy); a benchmark "sidecar" restoring ids/versions is an outsider-buildable fix that does not break frozen leaderboards.
4. Qualifier stripping (">300" -> 300.0; 382 cells) turns censored labels into exact ones — a concrete, checkable label-noise source for ML.
5. Computed data gets remade because the recipe can be rerun; experimental data cannot, so the leverage is in complete-by-design new datasets plus round robins, not retrofits.
