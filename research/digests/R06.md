# R06 — Discovered Materials (DM) Debrief: the synthesis gate is unchecked against real outcomes

## 1. What this slice is (2-3 plain sentences)
A published debrief (dated 15 Sep 2026), companion to the earlier report "Discovered Materials Data Gaps (version 1)", about one YC-backed startup, Discovered Materials (DM), that uses LLM agents to propose new thin-film materials for chip cooling. ## 5. Problems / gaps identified
- B1 (ranked 1st): no public recipe-to-outcome records at <= 400 C (chip wiring-layer limit), failures included, with failure causes separated (chemistry, tool failure, inconclusive characterization, run not finished). Evidence: no outcome field in any examined file. Hurts DM's gate validation and anyone benchmarking synthesis prediction. [OPINION deduction from OWN-EXPERIMENT]
- B2 (2nd): phase identity collapsed to yes/no adds label noise where candidates cluster (lonsdaleite vs faulted cubic diamond; BN polymorphs expected but not source-checked). [OPINION + SOURCE]
- B3 (3rd): computed bulk kappa vs real film kappa gap; reference table has no film data; affects ranking only. [OPINION, low confidence]
- Censored outcomes: refused recipes never run, so critical penalties are unfalsifiable. [OPINION]
- Evidence lost at predictable points: computed kappa has no uncertainty or bulk flag; recipe tied to no sample/tool; export omits per-criterion penalties and LLM-panel vs manual-override source; setpoint vs actual temperature, fit uncertainties and failure types would collapse into one label. [OPINION]
- Negative results unpublished; human-chosen experiments carry selection bias (Jia 2019). [SOURCE]
- Key evidence is access-restricted: DM run records (incl. BC4N attempt), grader internals, partner-lab notebooks. Unrecoverable: actual temps where only setpoints logged, chamber wall state, undocumented run differences, destroyed samples, unsaved raw TDTR signals. [OPINION]
- Leakage: cannot verify whether grader training data / web search already saw a paper's results; testable only via search-off and paraphrase checks. [OPINION]

## 10. Jargon that matters for the big picture
- Recipe grader / LLM judge — rubric-based LLM scoring of synthesis recipes; like a reward model trained on annotator preference.
- Property window — threshold filter on computed properties (kappa > 20 W/m-K, eps0 < 10, stiffness minima).
- kappa (thermal conductivity) — how well a material carries heat; the target metric.
- MLIP — machine-learned interatomic potential; a fast surrogate simulator producing "computed" values.
- Censored outcomes / selective labels — you only observe labels for items the gate let through.
- Phase identity — which crystal form actually formed; the ground-truth label, often ambiguous.
- Lonsdaleite — hexagonal diamond; disputed, easily confused with faulted cubic diamond.
- PVD / sputtering vs CVD — two families of thin-film deposition; determines which literature is relevant.
- Combinatorial library / co-sputtering — many compositions on one wafer; makes outcomes cheap (like batch inference).
- TDTR / 3-omega / FDTR — methods to measure film thermal conductivity; values are model fits.
- Cohen's kappa — inter-annotator agreement; 0.6 threshold here.
- Group-held-out split — hold out whole research groups to prevent leakage.
- Exploration arm — deliberately running random refused recipes (epsilon-greedy for labs).
- 400 C limit — max process temperature compatible with chip wiring layers.

## 12. Smart or non-obvious ideas worth not losing
- Treat an LLM-judge gate as a forecaster: log each rubric criterion as a prediction and score it against outcomes (Brier/AUROC) — outcome is the target, verdict is a forecast.
- Selective-labels fix: a small random "exploration arm" of refused recipes is the only way a critical penalty can ever be refuted.
- Start prospective logging now with the one public verdict (BC4N): verdict before run, outcome after — "every unlogged run is lost for good".
- Use replicate groups to estimate the noise ceiling on any predictor before blaming the model.
- Full-record vs summary-only learner comparison answers whether detailed curation is worth its cost.
