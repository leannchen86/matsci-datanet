## 4. Findings
**Periodic's posts (all [SOURCE], Sept 15 2026)**
- Neon = 1T-param model post-trained from open-weight Kimi K2.6 (midtraining on literature/code/experimental data + RL on own lab data), deployed for XRD analysis in superconductor/magnet labs; 1,300 H200 GPUs. So what: a company turned private lab data into a working analyst.
- FrontierXRD (internal): 134 hard samples, accepted fits average 5 phases; Neon 55.3% vs base 2.7% (20x). Held-out chemical-system set: 198 measurements, Neon ~76.5% (chart read), "easier than FrontierXRD"; smaller subsystems may appear in training.
- Harness, same model (Opus 5): Periodic harness (lab context + in-house structure/simulation DBs + XRD software) 31.53% at $5.41/attempt vs Claude Code + COD + Materials Project + BGMN 8.33% at $4.56 (3.8x). So what: public tools/databases alone fall far short; context is the lever. Not an ablation.
- Judge: PhD experts, 3 per pattern, rubric quality ratings on "thousands" of patterns; expert-expert 77.2%, LLM-expert 74.6%, LLM vs consensus 84%; claim "neither ground-truth labels exist nor pattern-fitting suffice". Eval scored by Opus 5 + GPT-5.6-Sol ensemble; whether RL reward judge is the same: not stated.
- Context that decides a correct analysis: precursors, temperature, atmosphere, environment, handling history, related samples, literature, energetics, simulations (oxide if heated in air; hydroxide only if moisture exposure possible). Expert analysis "can take several hours... per pattern".
- Cumulative gains chart (separate runs, approx): 4.5 -> 12 (multi-task RL) -> 17 (scaling lab data) -> 26 (midtraining) -> 33.5 (multimodal RL) -> 43.5 (LLM-judge compute + lab data) -> 55.3 (longer context + compute).

Only infra code upstreamed (SGLang PR #24851, Miles PR #1371, Megatron offload). Kimi K2.6 Modified MIT would permit weight release. `periodic-oss` GitHub org: 0 repos. $300M a16z-led round. ## 5. Problems / gaps identified
- Private labs hold the data: none of Periodic, Lila, Radical AI, CuspAI, DeepMind UK has released own-lab data — hurts everyone outside [SOURCE+OPINION].
- No hidden-label (sequestered) XRD or synthesis benchmark; public answers likely in LLM pretraining — hurts model evaluators [SOURCE/OPINION].
- No multi-rater label set for hard multiphase reaction products; single annotator treated as truth — hurts benchmark builders [SOURCE].
- No external ground truth checking experts themselves (weighed mixtures only 2-3 phases, n=20) [SOURCE].
- Handling history (humidity, exposure time, storage, synthesis-to-measurement time) has no schema field anywhere checked [SOURCE].
- No community rule for when two phase assignments are "the same" (solid solutions, ordered/disordered, polymorph naming); reference structures locked by licence [SOURCE].
- Property negatives lack measurement floors; no raw-curve repository [SOURCE].
- Periodic's evidence is thin statistically (n=134, no seed variance, undefined error bars, closed judge) [OPINION].
- Throughput: 100/day -> ~27 yr to 1M labels; hundreds/day -> 9-14 yr; A-Lab ~21/day -> ~130 yr (conditional forecast) [OPINION].

## 6. Things proposed to build
1. **Hard multiphase XRD, every rater's label kept** — specified, high/conditional. First step: count patterns with >=4 refined phases in Precursor Genome + GPSS; if enough, >=3 raters under a published rubric. Blockers: expert time, pairwise reactions may rarely give 5 phases. Data: both CC BY public; text does NOT say they are on the user's disk.
2. **Weighed-mixture ground truth** — idea, high. Needs >=5 phases, disorder/enantiomorph cases, several instruments, sequestered split; needs a lab; cost unknown.
3. **Handling-history schema + failure-inclusive logs** — specified, high, audit first: map both releases into one draft schema, list Periodic's context fields that go unrecorded, propose fields to NeXus/pynxtools-xrd, pdCIF, NOMAD. Limit: proving sufficiency needs a new campaign.
4. **Blind XRD challenge** — idea, medium; extend XRDBench E2E with a lab-context tool; needs donated samples and items 1-2.
5. **Open judge calibration** — idea, medium: rubric, all expert scores, logged judge versions/prompts/outputs, one open-weight judge, judge labels kept separate.
6. **Structure crosswalk + equivalence rules** — idea, medium; scoped to phases in 1-2; licence limits.
7. **Superconductor/magnet negatives with floors + raw curves** — idea, low.
8. **Specimen schema + benchmark rules for one property family (thermoelectrics)** — offered twice, not taken up here; a separate session produced Thermoelectric Benchmark Spec draft 0.2 (no pilot lab, cost estimate, or baselines).

## 10. Jargon
- XRD powder pattern — a material's fingerprint spectrum; multiphase = several fingerprints overlaid.
- Phase ID — multi-label classification of which crystals are in the sample.
- Rietveld refinement / Rwp — curve-fit of simulated to measured pattern / its residual (low loss can still be chemically wrong).
- Harness — agent tool/context scaffold around the LLM.
- LLM judge — model-graded reward where no ground truth exists.
- Midtraining — continued pretraining on domain data before RL.
- Held-out chemical systems — group split by element set to avoid leakage.
- Weighed mixture — sample of known composition; true labels.
- Sequestered split — hidden test labels (ILSVRC/CASP style).
- Round robin — same sample to many labs; inter-annotator agreement for instruments.
- Disorder / enantiomorph — mixed-site or mirror-image structures that databases handle inconsistently.
- Handling history — sample metadata (air, moisture, storage) that changes the right answer.
- Measurement floor — lowest temperature tested; a "negative" without it is an unbounded label.
- pdCIF / NXsample / NOMAD — metadata schemas for diffraction and samples.

## 12. Smart or non-obvious ideas worth not losing
- Periodic's own context list is a ready-made target spec for the missing-metadata schema.
- The community's niche is shared evaluation ground truth, which companies have little reason to release and which can exist years before an ImageNet-scale corpus.
- Only known-composition specimens can check both the experts and the LLM judge.
- Store failures ORD-style (record product measurements, no success flag) so negatives need no special handling.
- Keep judge labels versioned and separate from expert labels; include an open-weight judge because closed models get retired.
