## 10. Jargon that matters
- XRD pattern — 1D signal of peaks vs angle; the "image" that must be labeled with phases.
- Phase — one crystalline compound/structure in a sample; phase ID = multi-label classification.
- Hard pattern — scan whose best fit has >=4 phases (overlapping peaks, minor phases easily missed).
- Rietveld refinement — fitting a physics model to the whole pattern to get phase weight fractions; the human "annotation".
- Rwp — fit residual; lower is better (a loss value, not correctness).
- Weighed mixture — powders mixed at known masses; true ground truth labels.
- ICSD/ICDD vs COD/MP — paywalled vs open structure databases; ids are the label vocabulary.
- Crosswalk — id mapping table between those vocabularies.
- Space group / polymorph — symmetry class; same formula can be different phases (alpha vs beta quartz).
- Enantiomorph/handedness — mirror-image structures; invisible to powder XRD.
- StructureMatcher — pymatgen's "are these two structures the same" function; the would-be label-equality test.
- Sequestered split — hidden test labels (CASP/Kaggle-style).
- Pre-registration — fix the pass/fail rule before looking at data.
- Cluster bootstrap — resampling by mixture to get confidence intervals when items are not independent.
- Handling history — metadata on air/moisture exposure, storage, time before measurement.
