## 5. Problems / gaps identified in the field or in the data
- No agreed definition of "the same specimen" (composition insufficient; processing, state, scale matter) — three Mw, 1,604 silica rows, Ghiringhelli calls equivalent samples very hard — hurts anyone pooling experimental data — [OWN-EXPERIMENT]+[SOURCE].
- No persistent sample/position ids and no cross-database id joins — RRUFF/COD/MP; HTEM positions; Matbench drops MP id + version — hurts traceability, dedup, leak control — [OWN-EXPERIMENT].
- Uncertainty missing (6/9) and censored values flattened (">300" -> 300) — hurts noise-ceiling and metric design — [OWN-EXPERIMENT].
- Benchmarks average away processing (842 -> 312) and define tasks on composition only — hurts metal-property ML — [OWN-EXPERIMENT].
- Few experimental fixed tasks; no blind test outside CCDC CSP (molecular crystals only, with a leak incident) — [SOURCE].
- Bulk access, not license type, is the blocker — ICSD API tied to one named project; MPDS from EUR 9,500/yr academic; PoLyInfo bans bulk download; ImageNet itself was non-commercial — [SOURCE].
- Literature is biased and failures missing — 17% of amines in 79% of compounds (Jia 2019; randomized small set beat larger human-chosen set); Sun & David 2025 on text-mined recipes; MEAD v1 omitted failed measurements; only ~10% of HTEM entries published — [SOURCE].
- All large "labels" are 0 K DFT (no entropy, disorder, dynamic stability); PBE volume error inherited — [SOURCE]+[OWN-EXPERIMENT].
- Atlas's own limits: 9 cases cannot show prevalence; defines no task/split/metric; produces no data, incentives or cost estimates — [OPINION].

## 10. Jargon that matters for the big picture
- DFT — quantum simulation that produces most "labels"; like synthetic labels from a simulator, all at 0 K.
- PBE/GGA vs r2SCAN — simulator settings; different settings give different labels for the same crystal (label-definition drift).
- Provenance — lineage of a row (source id, version, method); dataset-card metadata at row level.
- Enantiomorph / space group #152 vs #154 — mirror-image crystal forms; a join key that silently mismatches.
- Specimen identity — what must be fixed beyond composition before two samples are "the same class".
- MPtrj / Matbench / Matbench Discovery — training set of DFT relaxation frames / 13-task fixed benchmark / stability-screening leaderboard (F1).
- GNoME — DeepMind's candidate-crystal release; candidates, not released training data.
- PIF (Citrine) / PSMILES — legacy record format / polymer repeat-unit string with no stereochemistry.
- FAIR / "wh- questions" — metadata should answer who, what, when, where, why, how.
- Round robin — many labs measure one specimen; gives label noise between annotators.
- Blind test / CASP — predictions scored against unpublished results; a held-out set that cannot leak.
- Reanalysis (ERA5) — physics model fused with observations; DFT databases are "reanalysis with no observations".
- ZT — thermoelectric figure of merit; 19% between-lab uncertainty.
- Confounding — two variables always change together, so no model can separate them.
- Censored value — ">300" stored as 300; label clipping.

## 12. Smart or non-obvious ideas worth not losing
- Split every gap into "fixable by documentation/linking" vs "needs new experiments/calculations" — the doc-only column is the low-hanging-fruit list for a data/ML person.
- Follow one material (quartz) through specimen -> DFT -> training set -> benchmark -> candidate release to expose where ids, versions and physics drift; reusable as a provenance-audit method.
- ImageNet's lesson is protocol stability (rankings survived 6% label error and an 11–14% re-test drop), so a materials benchmark needs fixed task + hidden test more than clean labels.
- PDB+CASP order of operations: deposition policy with embargo first, neutral blind test second, the model breakthrough last (AlphaFold2 trained on <150,000 structures).
- Bulk access, not license type, is the blocker; keep censored values (>, <, ranges) and unaveraged records alongside any averages.
