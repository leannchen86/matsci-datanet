the recommendation

Make the exam fair before making anything bigger. Start with the X-ray marking kit, inside your own project.

Both earlier recommendations are the same kind of work: making the exam fair. They differ only in where to commit a month or more. Three independent planners, given everything on this page, landed on the same answer.

  • A first user already exists: you. Your dara-conform project needs a fair marker, and its own written fallback is “shrink to the evaluation harness”. The thermoelectric tools have no named user yet.
  • In X-ray data the input really contains the answer. In thermoelectrics a formula-only model has a 15.0% error floor even with perfect labels, so a benchmark on today’s data mostly measures missing information.
  • The marking rule moves the score from 12 to 32 of 40. That sits upstream of every X-ray exam anyone will ever run, and fixing it is desk work.

Thermoelectrics or X-ray? For the next three weeks it is a false choice: the quick wins on both sides have the same shape (a small verified list plus a tiny checker). The fork only appears at the one-to-two-month commitment, and there X-ray becomes the main line. Switch back if no diffraction specialist will look at 25 rows within about two weeks, or a proper search finds that a working marking tool already exists.

It is the fallback you already chose. Only you can call it.
